# همسفر سرویس مدارس (hamsafar_school)

اپلیکیشن راننده سرویس مدارس. لیست دانش‌آموزان **همان اپ است**: ترتیب سوار کردن،
آدرس هر در، و دو دکمه برای ثبت سوار و پیاده شدن.

## روال کار

1. سرویس‌های امروز (معمولاً رفت و برگشت) روی صفحهٔ اول.
2. با «شروع سرویس» ارسال موقعیت آغاز می‌شود و اولیا می‌توانند خودرو را ببینند.
3. هر دانش‌آموز در محل خودش «سوار شد» یا «غایب» ثبت می‌شود؛ موقعیت خودرو به ثبت
   پیوست می‌شود.
4. با «پایان سرویس» ارسال موقعیت قطع می‌شود و اولیا دیگر خودرو را نمی‌بینند.

## قواعد حریم خصوصی

- موقعیت خودرو فقط در زمان اجرای سرویس ارسال می‌شود؛ خارج از آن هیچ خانواده‌ای
  حق دیدن آن را ندارد و سرور گزارش را نمی‌پذیرد.
- هر خانواده فقط سرویس فرزند خودش را می‌بیند و فقط تا وقتی سفر فرزندش تمام نشده
  است.
- یادداشت پزشکی و شماره تماس اضطراری روی همان کارتی است که راننده در لحظهٔ نیاز
  به آن نگاه می‌کند.

## اجرا

```bash
cd packages/hamsafar_core && flutter pub get
cd ../../apps/school_driver && flutter pub get

flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```
