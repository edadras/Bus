# همسفر تاکسی (hamsafar_taxi)

اپلیکیشن راننده تاکسی. یک ناوگان و سه خدمت متفاوت:

| حالت | کرایه | نقش راننده |
|---|---|---|
| تاکسی خطی | کرایه ثابت خط | فقط بارکد را نشان می‌دهد |
| دربست | مبلغی که راننده اعلام می‌کند | مبلغ را در اپ وارد می‌کند |
| تاکسی‌متر | بر اساس مسافت و توقف | کاری لازم نیست؛ خودکار محاسبه می‌شود |

نوع خدمت روی **شیفت** ثبت می‌شود، نه روی خودرو: یک ماشین صبح خطی کار می‌کند و
بعدازظهر دربست، بدون اینکه شیفت بسته شود.

## نکات مهم

- بارکد کرایه ثابت نیست؛ هر ۳۰ ثانیه توکن جدیدی صادر می‌شود، پس عکس گرفتن از
  صفحه بی‌فایده است.
- مسافت تاکسی‌متر از گزارش موقعیت **خودرو** محاسبه می‌شود، نه از گوشی مسافر.
- تا وقتی شیفت باز است، موقعیت خودرو ارسال می‌شود؛ با پایان شیفت متوقف می‌شود.

## اجرا

```bash
cd packages/hamsafar_core && flutter pub get
cd ../../apps/taxi_driver && flutter pub get

flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```
